# farenough promo

A 20-second landscape promo made with Remotion 4.0.539, React and TypeScript. The video uses the app name **farenough**, its existing colours and logo, and the official download address.

Output: `out/farenough-promo-20s.mp4`, 1920 × 1080, 30 fps, 600 frames, H.264 video and AAC audio. The render is local. No account or paid rendering service is needed.

[Watch the published promo](https://holsoma.github.io/farenough/videos/farenough-promo-20s.mp4). The main repository README links to this export. Its published copy and preview image live in `site/public/videos/`.

## Preview and render

Use Node.js 24 and npm:

```sh
npm ci
npm run dev -- --port=3115
npm run lint
npm run stills
npm run render
npm run verify
```

Select **FarenoughPromo** in Studio. Each scene also has a separate composition under **Scenes**, with its own editable timeline. Animation is driven by frame numbers, so the preview and MP4 use the same timing. The render command uses one worker to limit memory use.

The sound file is included. Regenerate it with Python 3 if changing the timing:

```sh
python scripts/make-audio.py
```

## Storyboard

| Start | Scene | Purpose |
| --- | --- | --- |
| 0.0 s | Has your pass paid for itself? | Introduce the question and an example S$48 train pass. |
| 3.2 s | Every trip adds up | Animate the counter from 0 to 26, with one marker per journey. |
| 6.4 s | See when it pays off | Animate recorded fares to S$57.20 against S$48.00, ending with S$9.20 estimated savings. |
| 10.4 s | Your months, side by side | Show the actual v0.3.0 month-comparison screen. |
| 13.2 s | Spot your busiest months | Change the phone to the app's month-history graph and animate matching journey totals beside it. |
| 16.8 s | farenough | Hold the Android download action and website address until 20.0 s. |

Each scene overlaps the next by 12 frames. The five scene lengths total 648 frames; four overlaps leave exactly 600 frames. The phone changes screen within the Insights scene. No voiceover is used, and the message remains readable with sound off.

## Assets and claims

- The figures and app records are demonstration data, labelled on screen. They do not imply that every set of 26 journeys covers a pass.
- The logo and screenshots are copied from this repository. The graph uses the same demonstration totals: August 22 journeys, September 32, October 26. It compares months, without claiming time-of-day analytics. No personal travel history or fare dataset is part of this project.
- Archivo is bundled locally with its [SIL Open Font Licence](public/fonts/Archivo-OFL.txt).
- The sound cues and chord bed are generated by `scripts/make-audio.py`. No external music or sound recording is used.
- Project source follows the repository's Apache 2.0 licence. Remotion and other dependencies retain their own [licence terms](https://www.remotion.dev/license).

## Verification

The source passes ESLint and TypeScript checks. Seven rendered scene frames are inspected before export. The export step trims AAC padding to exactly 20 seconds and enables playback before the whole file downloads, without re-encoding the video. `npm run verify` checks duration, dimensions, codecs, all 600 decoded frames and audio level, saving `out/verification.json`. Rendered files stay in the ignored `out/` directory.
